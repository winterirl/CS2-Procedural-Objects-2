# Procedural Objects 2
Procedural Objects 2 lets you create Procedural Objects - editable, texturable 3d-meshes - inside of Cities Skylines 2.

I don't even know what to say. This project is stupid, and I'm an idiot for spending most of 2026 doing this. I stumbled my way through it, had a lot of fun, learned a lot of new things about 3d programming, and somehow ended up with a usable piece of software.
